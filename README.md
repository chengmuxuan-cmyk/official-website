# official-website

官网前端项目，基于 `Vue 3 + TypeScript + Vite` 构建，并集成 `Tailwind CSS`、`Element Plus`、`Swiper`、`ECharts` 等能力，用于企业官网或品牌展示站点。

## 技术栈

- Vue 3
- TypeScript
- Vite 7
- Tailwind CSS 4
- Element Plus
- Vue Router
- Axios
- Swiper
- ECharts

## 本地开发

```bash
npm install
npm run dev
```

## 构建命令

```bash
npm run build
npm run preview
```

## 项目结构

- `src/`: 页面、组件、路由和业务逻辑
- `public/`: 静态资源
- `.env*`: 环境配置
- `vite.config.ts`: 构建配置
